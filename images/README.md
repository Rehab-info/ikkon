# お酒の写真

銘柄の写真を置くフォルダです。写真がない銘柄には、瓶のイラストが自動で表示されます。

## 追加の手順

1. 写真をこのフォルダに入れる(例:`images/dassai45.jpg`)
   - 縦長(横3:縦5くらい)だときれいに収まります
   - 横幅600px程度、1枚200KB前後までに縮小しておくと表示が速くなります
2. `data/sakes.json` の該当銘柄に `"photo": "images/dassai45.jpg"` を追加する

## 使える写真

- ご自身で撮影した写真
- 蔵元や販売店から掲載の許可を得た写真

ネット上の商品画像やほかのサイトの写真は、著作権があるため使わないでください。
