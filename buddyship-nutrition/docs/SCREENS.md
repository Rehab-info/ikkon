## 主要画面の詳細

### M-04 食事を記録:確認・修正

```
┌──────────────────────────────┐
│ [写真サムネイル]               │
│ 昼食 ▼   2026-11-09 12:30 ▼   │
│ ⚠ AIによる推定です。食品と重さを確認してください │
├──────────────────────────────┤
│ ごはん(精白米)       [候補▼] │
│   150 g [−][+]   252 kcal     │
│   P 3.8  F 0.5  C 55.7        │
│                        [削除] │
├──────────────────────────────┤
│ 鶏から揚げ             [候補▼] │
│   ...                         │
├──────────────────────────────┤
│ [+ 食品を追加]                 │
├──────────────────────────────┤
│ 合計(推定) 620 kcal         │
│ P 28.1 g  F 24.0 g  C 70.2 g  │
│           [保存]              │
└──────────────────────────────┘
```

- AIの信頼度が低い行(閾値は [未決 D-14])は「要確認」マークを付ける。
- 照合できなかった行は「食品を選んでください」と表示し、未選択のままでは保存できない。
- 重量の入力範囲:1〜2000 g(仮)。
- 計算は即時(クライアント)、保存時にサーバーで再計算し、差があればサーバー値を表示。

### M-10 同意の管理

- 各範囲は個別にオン/オフ。オフにすると確認ダイアログ「〇〇さんは今後この情報を見られなくなります。すでに見た情報は取り消せません。」
- 撤回は即時反映。履歴(付与日時・撤回日時・文面の版)を表示。

### T-01 / T-02 スタッフ画面

- 一覧取得時点の範囲を表示するが、詳細を開くたびにサーバーで再判定。拒否された場合は「同意が撤回されたか担当が外れました」と表示し、画面上のデータを破棄する。
- スタッフ端末では利用者データを永続キャッシュしない(React Query の永続化を使わない、画面離脱で破棄)。

### M-11 アカウント削除

- 再認証(OTP)→「削除」と入力 → 実行。削除対象と保持されるもの(仮名化された監査ログ)を明示。

## アクセシビリティ

- グラフは色だけでなく線種・マーカーで区別し、数値表を併記(切替)。
- すべての入力にラベル、エラーは `aria-live` で通知。
- タップ領域 44×44px 以上。
