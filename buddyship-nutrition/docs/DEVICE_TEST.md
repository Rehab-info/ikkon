# DEVICE_TEST — 実機テストの手順(HEIC・iPhone・Android・PWA)

- 文書版: v0.1/Sprint 3(手順のみ。**実施は Sprint 4**、staging 環境の承認後)
- 使うもの:**架空のアカウントと、テスト用に撮った食事の写真だけ**(利用者の端末・写真・データは使わない)。写真に顔・郵便物・薬袋を写さない。
- 記録:端末名・OS の版・ブラウザの版・日時・結果(合格/不合格/保留)・画面の写真(個人情報が写らないもの)。

## 1. 端末

| 区分 | 最低限 | 備考 |
|---|---|---|
| iPhone | 現行の iOS と 1 つ前の版、各 1 台 | Safari と、ホーム画面に追加した PWA |
| Android | 現行の Android と 2 つ前の版、各 1 台(メーカー違いが望ましい) | Chrome と、インストールした PWA |
| 文字サイズ | 端末の文字サイズを最大にした状態を 1 台ずつ | アプリの「とても大きく」と組み合わせる |

## 2. 写真(HEIC を含む)

| ID | 手順 | 期待する結果 |
|---|---|---|
| P-01 | iPhone の「設定 → カメラ → フォーマット」を「高効率」(HEIC)にして撮影 → 食事の記録で「写真を撮る・選ぶ」→ カメラで撮る | 端末が JPEG に変換して渡す場合は記録できる。読めない場合は「この写真の形式(HEIC)は…『互換性優先』…『写真なしで記録する』」の案内が出て、写真なしで続けられる |
| P-02 | P-01 の設定のまま、写真ライブラリから HEIC の写真を選ぶ | P-01 と同じ。画面が止まらない |
| P-03 | 「互換性優先」(JPEG)で撮影・選択 | 解析に進む |
| P-04 | Android の標準カメラで撮影・ギャラリーから選択(HEIF 設定がある端末は HEIF でも) | 解析に進む、または案内が出る |
| P-05 | 30 MB を超える画像(パノラマ等)を選ぶ | 「写真が大きすぎて読み込めません(30 MB まで)」 |
| P-06 | 写真以外(PDF など)を選べる端末で選ぶ | 「写真のファイルを選んでください」 |
| P-07 | 縦長・横長・回転情報つきの写真 | 向きが正しく、縮小(長辺 1600px)されて送られる |
| P-08 | 送った画像の位置情報 | 開発者が Storage の画像を取り出し、EXIF(位置情報など)が残っていないことを確認(端末で描き直すため) |
| P-09 | 通信を切った状態で写真を送る | 平易なエラーが出て、もう一度送れる。二重に保存されない |

## 3. 画面・操作

| ID | 手順 | 期待する結果 |
|---|---|---|
| U-01 | 主要画面(ホーム・食事の記録・確認・一覧・InBody の入力・体の変化・見せる情報)を、最大の文字サイズ・320px 幅相当で表示 | 文字が切れない・重ならない。横にスクロールしない(表は表の中だけでスクロール) |
| U-02 | 画面下部の主ボタン(次へ・確認へ)が、入力欄や最後の項目を隠さない | 最後の項目まで見て操作できる(Sprint 2 で気づいた点の確認) |
| U-03 | 数の入力でキーボードが数字用になる(inputMode=decimal) | 数字と小数点が打てる。全角で入っても読める |
| U-04 | 測定日時の入力(iOS・Android の日時ピッカー) | 選べる。未来の日時は保存できない |
| U-05 | グラフの点に触れる | 日時・値・機械が表示される。指で隠れても表で確認できる |
| U-06 | 読み上げ(VoiceOver・TalkBack)で InBody の入力と確認画面を操作 | 各ボタン・入力欄の名前が読まれる。エラーが読み上げられる |

## 4. PWA

| ID | 手順 | 期待する結果 |
|---|---|---|
| W-01 | iPhone の Safari で「ホーム画面に追加」→ 起動 | アプリとして開き、ログインできる |
| W-02 | Android の Chrome で「アプリをインストール」→ 起動 | 同上 |
| W-03 | PWA から写真を撮る・選ぶ | ブラウザと同じに動く(P-01〜P-04) |
| W-04 | オフラインで起動 | アプリの外枠とオフラインの表示だけ。健康データは表示されない(端末に保存しない) |
| W-05 | 新しい版を配信 → 再起動 | 新しい版に切り替わる。古い画面のまま保存できない |
| W-06 | 共用端末を想定し、スタッフで 15 分操作しない | 自動でログアウトし、戻るボタンで前の画面のデータが見えない |

## 5. 不合格のとき

- 写真が読めない端末・形式は、案内の文言(写真なしで記録する)で続けられることを最低条件にする。読めない形式の割合が多い場合は、変換の方法(サーバーでの変換など)を D-11 として改めて相談する。
- 結果は Sprint 4 の報告書にまとめる。
