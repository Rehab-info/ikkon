# FIT NOTE — 体型と流行から選ぶコーデ

インボディの測定データ・年齢・性別・好みから、今季の流行に合わせて体型に合うコーディネートを提案する静的サイトです。
公開後は `https://<ユーザー名>.github.io/ikkon/fit/` で開けます。手元では `python3 -m http.server 8000` → `http://localhost:8000/fit/`。

## 使い方(3ステップ)

1. **からだ** — インボディの CSV をドロップ(LookinBody の書き出しなど。Shift_JIS・UTF-8、横持ち/「項目,値」の縦持ち、JSON に対応)。手入力やサンプルも可。
2. **あなた** — 年齢と、提案してほしい服(レディース/メンズ/こだわらない)。
3. **好み** — テイスト・色・場面・避けたいもの・流行の取り入れ度。

データはブラウザ内だけで処理し、送信・保存しません。

## 判定のしくみ(目安)

| 体型 | おもな判定材料 |
|---|---|
| 中心ボリューム(O) | ウエストヒップ比が標準より高い / 内臓脂肪レベル10以上 / BMI25以上かつ体脂肪率高め |
| 逆三角(Y) | 部位別筋肉量で「腕+体幹 ÷ 脚」が 1.92 超 |
| 下重心(A) | 同比率が 1.58 未満、または体脂肪の多くが脚に集中 |
| 細身ストレート(I) | BMI 19.5 未満 |
| くびれ(X) | ウエストヒップ比が低め |
| バランス(H) | 上記以外 |

骨格タイプ(ストレート/ウェーブ/ナチュラル)は筋肉量・身長・脂肪のつき方からの参考推定です。

## 流行を更新する

`data/trends.json` の `seasons` の先頭に新しい季節を追加します。`period`(YYYY-MM〜YYYY-MM)に今日が入る季節が自動で選ばれます。該当がないと、最新のデータを使いつつ「古い」と表示します。定番アイテムは `data/catalog.json`。

## デザインの差し替え

`style.css` 冒頭の `:root` の変数(色・フォント・角丸)を変えるだけで全体が変わります。ムードボード反映時はここから。
